How it works

  • Chrome’s local notebook remains the main copy of your notes.
  • After you choose a file, new notes and deletions are copied into it when Chrome has write access.
  • If Chrome asks for permission again, open this page and choose “Reconnect and update.” The notebook continues saving while the file is disconnected.
  • The extension replaces the text file contents with the current notebook. Hand edits to the file can be overwritten on the next update.
  • Disconnecting the file stops future updates but does not delete the file.
